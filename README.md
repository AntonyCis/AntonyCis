## 📂 Proyectos Destacados

### 🤖 AI Job Interview Simulator *(Proyecto de Integración Curricular)*
Sistema web inteligente para la simulación de entrevistas laborales técnicas. El sistema interactúa en tiempo real con los usuarios simulando un reclutador y ofrece retroalimentación automatizada sobre el desempeño técnico y habilidades blandas mediante Inteligencia Artificial.
* **Tecnologías:** React, Node.js, MongoDB, Express, API Integration con modelos LLM.

### 📱 CV-CREATOR
Aplicación móvil nativa moderna orientada a la creación y personalización de currículums profesionales de manera rápida y dinámica desde dispositivos móviles.
* **Tecnologías:** React Native, Expo, JavaScript, Tailwind CSS.

### 🗺️ Polimaps
Aplicación web enfocada en optimización de rendimiento y renderizado web, mejorando métricas críticas de Core Web Vitals como el *Largest Contentful Paint* (LCP).
* **Tecnologías:** JavaScript, CSS Avanzado, Firebase.

### 📅 Sistema Comercial de Gestión de Citas
CRUD de nivel empresarial para la automatización, control y agendamiento de citas de clientes, optimizado para soportar flujos intensivos de datos.
* **Tecnologías:** PHP, MySQL, JavaScript.
